# Pilot Outreach

DM three active moderators before locking the feature freeze. The goal is not praise; the goal is to find the unsafe edge.

## Short DM

Hi! We are building a Devvit app for the Reddit Mod Tools hackathon called Casefile Guard.

It watches modmail for repeat harassment or ban-evasion burner accounts, groups related messages into one mod-only casefile, and generates a clean escalation packet with accounts, timestamps, conversation IDs, and moderator notes. It defaults to internal notes only; auto-archive is opt-in after a sender is already linked to a case.

Would your mod team install this on a test subreddit? What would make it unsafe or annoying?

## Questions To Ask

1. How often do you deal with repeat abusive modmail or burner-account ban evasion?
2. What do you currently have to copy into reports or escalation modmails?
3. Would you trust auto-archive if it only applies to accounts already linked by a mod?
4. What data should the app never store?
5. What would make the App Directory listing trustworthy enough to install?

## Pilot Success Bar

Proceed if at least two moderators say they would install it or test it.

Kill or pivot if moderators say the core problem is already solved by AutoModmail, AegisMod, or Modmail Automator for their team.
